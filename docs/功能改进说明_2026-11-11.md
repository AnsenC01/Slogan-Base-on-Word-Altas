## 一、概述

本轮开发围绕缺失功能清单第 1 项「单词释义不完全」展开，并按用户逐轮反馈完成了词卡信息组织、按钮布局、发音控件与单手操作排序等一系列界面改进。

**边界说明**：用户明确选择「全义项 + 两条例句 + 同义词/反义词/辨析」，等于放宽 `docs/PRD.md` 的 MVP 范围（PRD 未列 `syn/ant/note` 与多例句文本）；除此之外仍严格遵守 PRD「明确不做」清单，PRD 已定义字段名未修改，未引入账号、云同步、社交、音效或星图能力。

### 1. 补全词条释义（`1d0e351`）

- **根因**：上游 `word-atlas.json` 每词有 1–3 个义项、2 条例句，旧构建脚本只取 `senses[0]` 与 `ex[0]`，7298 词中有 4608 个多义词被丢弃释义。
- **数据链路**：`scripts/build-vocab.mjs` 的详情行改为 9 元组 `[id, senses, examples, collocations, wordFamily, usageTip, synonyms, antonyms, note]`，`senses = [[pos, zh, en], ...]`、`examples = [[en, zh], ...]`；新增 `app.json` 数据分包注册一致性断言，避免重跑构建后 `require.async` 找不到模块。
- **类型与合并**：`types/index.ts` 新增 `WordSense`、`WordExample` 及 `senses/examples/synonyms/antonyms/note`；`services/word-repo.ts` 合并时让 PRD 既有字段 `meaningEN/example/exampleCN` 取首义项、首例句，练习题干与词库列表口径不变。
- **展示**：`word-card` 逐条列出全部义项（编号 + 词性 + 中英释义）、两条例句、搭配、词族、同义词、反义词、辨析与用法注意；例句英文常驻，中文译文随「显示释义」显隐。
- **体积**：详情数据 2.70MB → 5.07MB，数据分包由 `vocab-a/b` 扩为 `vocab-a~d`（1394 / 1447 / 1454 / 929KB，均 < 1.9MB）；主包索引仍为 706KB，未变化。

### 2. 例句位置（`da8f10b`）

词卡顺序调整为 **释义（全义项）→ 搭配 → 例句 1/2 → 词族 → 同义词/反义词 → 辨析与用法注意**。为保留 v1.0.0 定稿的显隐逻辑，释义区拆成两段 `wx:if="{{showMeaning}}"`，例句块置于两段之间、不受翻卡控制；`.meaning-more` 收紧后段间距。

### 3. 按钮并排与大腰形分段控件（`e492421`）

- 详情页「下一个单词 / 加入今日学习 / 标记已学」改为横排三等分；学习页评分后「隐藏释义 / 下一个」并排一行，未评分时该行仍只有翻卡按钮、下方三档自评不变。
- `app.wxss` 新增 `.audio-group`（大腰形背景）与 `.audio-divider`；`audio-button` 新增 `grouped` 属性，分组态去掉独立胶囊边框、改为等分透明分段；练习页单个深色「播放发音」保持独立胶囊。

### 4. 文字居中与复习页排序（`646b400`）

- 小程序 `button` 的默认内部样式会让文字在分段内整体偏右，改用 `view` + 内嵌 `text`，宿主节点 `flex / stretch`，分组态显式双向居中并补 `font-weight:600` 恢复字重。
- 复习页快捷评分改为「不认识（左）/ 模糊（中）/ 认识（右，深色高亮）」，贴合单手拇指姿势；学习页三档自评原本就是此顺序。

### 5. 按下/播放态腰形高亮（`319bd03`）

旧实现直接给整段分段涂背景，首尾被容器 `overflow:hidden` 裁成半腰形、中间为矩形。改为组件内独立 `.audio-highlight` 层：四边内缩 8rpx、`border-radius:999rpx`，常态透明；按下（`hover-class`）、加载、播放时只给该层着色，形成两端圆角、与分隔线留隙的完整小腰形反馈；文字由 `.audio-label` 置于上层。三个页面的 9 个 `audio-button` 加 `class="audio-segment"` 供自动化定位。

### 6. 详情页按钮排序（`b784f0c`）

三枚操作按钮改为「加入今日学习（左）→ 标记已学（中）→ 下一个单词（右）」，深色主操作移到最右，与复习页排序逻辑一致。仅调整 `.detail-actions` 子节点顺序，样式与事件绑定不变。

## 三、关键约定

- **索引行**（主包）：`[id, word, meaningCN(首义项), ipaUK, ipaUS, cefr, topicId, pos]`，8 元组，本轮未变。
- **详情行**（分包）：9 元组，500 词/chunk，必须是**原生 CommonJS `.js`**（TS 编译插件不编译无静态引用的分包 `.ts`）。
- **分包映射**：`data/vocab-chunks.ts` 由构建脚本生成；分包数量随详情体积变化，重跑 `npm run build:vocab` 后须按脚本断言同步 `app.json` 的 `subPackages`（当前为 `vocab-a~d`）。
- **媒体**：仍由 `data/media.ts` 统一从云开发静态托管 CDN 运行时派生，不硬编码进数据文件。
- **两份 project 配置**的 `ignoreDevUnusedFiles` / `ignoreUploadUnusedFiles` 保持 `false`，否则动态加载的分包 chunk 会被静默过滤。
